# 常见问题

## 账号与费用

**需要注册若道账号吗？**

不需要。远控本身完全匿名：被控端生成远控码和访问密钥，主控端输入即可。只有「问 AI」和「发表社区留言」需要登录若道账号，这两项都是可选的，不影响远控。

**是免费的吗？**

客户端和服务端源码在本仓库发布，可以自行部署使用。若使用若道提供的公共服务或插件市场能力，以其页面说明为准。

**会把我的设备信息上传到若道吗？**

远控链路只经过你自己填写的信令服务器；客户端不会把远控码、访问密钥或画面发送给若道。AI 助手只在你主动提问时发送状态摘要和问题；社区留言只有你主动发布时才会公开。

## 安装与兼容性

**Windows 提示「未知发布者」/ SmartScreen 拦截怎么办？**

安装包目前没有代码签名。点击「更多信息」→「仍要运行」。如果介意，可以从源码自行构建并签名。

**360 等安全软件报毒或拦截安装？**

未签名安装包可能被启发式规则误报。请从本仓库 Releases 下载，校验 `SHA256SUMS.txt`，并把安装包加入信任。便携版被拦截时改用安装版。

**支持 macOS / Linux 客户端吗？**

目前客户端只提供 Windows x64。被控端的键鼠注入依赖 Win32 `SendInput`；主控端也使用同一个 Windows 客户端。服务端可以安装在 Linux。

**支持多显示器吗？**

当前只采集主显示器，不支持切换。

**能传文件、传音频、拖拽吗？**

暂不支持。剪贴板只同步纯文本（单条 64 KB），会话消息支持文字。

**支持无人值守吗？**

可以。在被控端打开「启动后自动被控」和「开机自动启动」，登录系统后会自动上线并生成新的远控码。需要固定入口时，使用服务器上的「共享设备」，由设备主人逐次批准。

## 连接

**两台电脑连不上，先检查什么？**

1. 两端「设置 → 服务器地址」完全一致（协议、域名、端口都要相同）；
2. 被控端显示「已上线」，并且没有其他会话占用（同一被控端同时只允许一个主控端）；
3. 被控端已点击「开始被控」，或开启了自动被控；
4. 服务器 `/health` 可访问，反向代理已转发 WebSocket；
5. 远控码和密钥没有抄错（密钥不含 `I`、`O`、`0`、`1`）。

**局域网需要服务器吗？**

需要一台设备运行信令服务。可以在其中一台 Windows 电脑上用客户端「本机服务端」启动，另一台设备填写这台电脑的局域网地址（例如 `http://192.168.1.20:8787`）。

**跨公网一定要 TURN 吗？**

不一定。双方能直连时只走 STUN；跨对称 NAT 或严格企业网络时，必须配置 TURN 才能建立连接。一键部署可以选择安装 coturn。

**为什么连接时提示「busy」？**

被控端同一时间只允许一个主控端。先结束已有会话，或被控端点击「更换密钥」使旧会话失效。

**远控码会一直有效吗？**

不会。远控码和密钥只在本次被控期间有效；客户端重启、停止被控或更换密钥后需要重新生成。服务器重启也会使进行中的会话失效。

## 安全

**服务器能看到我的屏幕吗？**

不能。画面和输入通过 WebRTC 的 DTLS-SRTP 端到端加密传输，服务器只转发 SDP/ICE 等信令，能看到设备名、平台、IP 和会话元数据。

**访问密钥存在服务器上吗？**

不存明文。服务器只保存随机盐和 PBKDF2-SHA256 哈希；主控端在本地派生哈希后再比对。

**密钥泄露了怎么办？**

立即在被控端点击「更换密钥」，旧密钥和旧会话会同时失效。之后通过可信渠道传递新密钥。

**管理员密码怎么保存？**

客户端使用系统加密存储（Windows DPAPI）保存，仅在需要管理服务器时使用；网页后台使用 HttpOnly Cookie。

**剪贴板同步安全吗？**

只同步纯文本，默认关闭，必须被控端允许、主控端再手动开启。剪贴板可能包含密码、验证码，请只在可信会话中开启。

## 使用中的问题

**画面黑屏或卡住？**

检查被控端是否锁屏、是否在 UAC 安全桌面、是否使用独占全屏；跨公网时检查 TURN 是否可用。也可以切换画质档位或重新连接。

**键盘鼠标没反应？**

被控端可能点击了「暂停操作」；部分受保护窗口（UAC、锁屏、独占全屏游戏）无法注入输入。控制端窗口失焦后需要重新点击画面。

**剪贴板不同步？**

需要双方都开启：被控端点击「剪贴板未允许」允许，主控端再点击顶部剪贴板按钮开启。只支持纯文本。

**会话聊天记录在哪？**

只在当前会话的两端内存中，断开即清空，不上传服务器。

## 更新

**客户端提示检查更新失败？**

确认能访问更新源（默认 `https://ruodao.com`），公司网络或代理可能拦截。更新包必须带 SHA-256 校验值，清单缺失校验值时客户端会拒绝下载。可以稍后重试，或到 Releases 手动下载覆盖安装。

**便携版能自动更新吗？**

不能覆盖正在运行的程序。客户端会把更新包下载到本机并打开所在目录，退出后手动替换。

**服务端更新是自动的吗？**

一键部署会安装 `ruodao-remote-update.timer`，由 root 每小时执行一次 `server.cjs --self-update`：发现新版本且没有远控会话时，自动下载校验、替换 `/opt/ruodao/server.cjs` 并重启，健康检查失败会回滚。服务进程本身以 `ruodao` 用户运行且不提权。手动安装的服务端或需要立即更新时，仍可在「服务端设置 → 服务端更新」下载后执行页面给出的一行 `sudo install ... && systemctl restart`。

**更新会中断远控吗？**

客户端安装会重启应用。服务端自动更新会检测 `/health` 中的会话数，有远控进行时自动推迟到下一次检查；手动立即更新或强制设置 `UPDATE_REQUIRE_IDLE=0` 时会断开当前会话，建议在空闲时操作。

## 服务端

**忘记管理员密码怎么办？**

SSH 登录服务器，修改 `/etc/ruodao-remote.env` 中的 `ADMIN_PASSWORD`（或删除 `ADMIN_PASSWORD_HASH`），然后执行 `systemctl restart ruodao-remote`。

**数据存在哪里？**

`/var/lib/ruodao/state.json`（设备、邀请码、审计日志）与 `/etc/ruodao-remote.env`（配置）。备份这两个文件即可。

**可以多台服务器共享数据吗？**

当前使用本地 `state.json`，没有外部数据库或高可用，多实例部署需要共享存储方案。

**端口被占用怎么办？**

一键部署会自动规划其他端口；手动部署可以修改 `PORT` 与反向代理配置。更换端口后记得同步修改客户端的服务器地址。

**服务器需要多大配置？**

信令服务本身很轻，1 核 1 GB 即可。真正的带宽消耗在 TURN 中继：跨 NAT 时画面流量会经过服务器，建议按并发会话数预留带宽。
